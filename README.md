# Daniel Dominic Chinemelum — Future Web Architect

Welcome to my personal portfolio repository! This is my active web workshop and digital home. It showcase my technical skills, problem-solving philosophy, selected projects, and features interactive integrations like a custom schedule booking simulator.

## 🌟 Key Features

- **Interactive Scheduler Simulator**: A custom, premium Cal.com-inspired virtual chat booking widget built directly into the hero section.
- **Dynamic Projects Showcase**: Fully filterable projects grid (built-in categorization for Vanilla JS versus React/TS).
- **Interactive Terminal Emulator**: A styled command line simulator showing key diagnostic info about me.
- **Milestone Roadmap**: A visual journey tracking my learning progress from foundational HTML/CSS to React and full-stack development.
- **Sleek, Modern Aesthetics**: Designed with curated HSL colors, soft glassmorphism, responsive typography, and micro-animations.

## 🛠️ Tech Stack & Skills

- **Structure**: HTML5 (Semantic document trees, SEO metadata structures, and ARIA attributes).
- **Style**: CSS3 (Custom variables systems, Flexbox, CSS Grid) & Tailwind CSS.
- **Behavior**: JavaScript (ES6+, DOM Manipulation, Async/Fetch APIs, state transitions).
- **Modern Web**: Deep-diving into React (component lifecycle, hooks, modular rendering).

---

## 📂 Repository Structure

- `index.html` - The main semantic markup containing the site structure.
- `style.css` - Custom, cohesive CSS resets, design tokens, variables, and custom layouts.
- `script.js` - Client-side interactive logic (animations, scheduler, menu toggle, contact handling).
- `tailwind.css` - Generated Tailwind stylesheet for utility class resolution.
- `package.json` - Build script configuration for Tailwind CSS generation.

## 🚀 Running the Project Locally

To run this project locally and watch CSS modifications:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Itz-Daniel/my-portfolio.git
   cd my-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Build Tailwind CSS styles:**
   ```bash
   npm run build
   ```

4. **Start the watch process (during development):**
   ```bash
   npm run watch
   ```

5. **Open in browser:**
   Open `index.html` directly in any web browser, or use a local development server like Live Server.
